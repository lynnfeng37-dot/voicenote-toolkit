# VoiceNote cover assets

- `voicenote-cover.png`: original AI-generated cover, kept at its native resolution.
- `voicenote-social-preview.jpg`: 1280 × 640 JPEG export, suitable for the README and GitHub social preview.

Generated with the built-in image generation tool on 2026-10-20. The JPEG export preserves
the composition and text; only image dimensions and encoding were changed for delivery.

## Upload to GitHub

Open the repository's **Settings → General → Social preview → Edit → Upload an image** and
select `voicenote-social-preview.jpg`. Committing the image or embedding it in the README
does not configure GitHub's social preview automatically.

GitHub recommends 1280 × 640 pixels and requires a file smaller than 1 MB.
[Official instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)
