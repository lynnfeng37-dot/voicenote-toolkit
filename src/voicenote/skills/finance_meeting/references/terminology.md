# Finance terminology reference policy

This file is a curation surface, not model training data and not an authority for changing source
text by itself.

Terminology matches may support a correction only when local context also supports it. Names,
tickers, dates, percentages, monetary values, valuation multiples, and financial metrics require
the sensitive-entity confidence thresholds. If evidence is weak, retain the recognized form and
mark it uncertain.

Initial high-value concepts include Sharpe ratio, information ratio, tracking error, basis points,
price-to-earnings, price-to-book, enterprise value, EBITDA, free cash flow, assets under management,
year over year, quarter over quarter, and compound annual growth rate. Localized forms and approved
organization-specific glossaries can be added without changing core code.
